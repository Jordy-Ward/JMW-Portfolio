\section{Honours Year}
\subsection*{Thesis - Cum Laude}
I built an interactive teaching tool for radio interferometry, a space science technique that  uses Earth-rotation aperture synthesis to capture celestial radio sources in remarkable detail. The tool is a React Native mobile app backed by a Python/Flask server that performs the interferometry computations. Students arrange coins on a tabletop and a custom fine-tuned YOLOv8 model detects those coins, whose positions are used to create a hypothetical radio telescope array. Rearranging the coins changes the array, which dictates the quality and resolution of the simulated image the student sees of their chosen radio source.

The primary focus of this project was its pedagogical capabilities. Built for a client from Rhodes University, the app can be used in real space science classrooms to help introduce and conceptualise radio interferometry.

Tech stack: Python, Flask, NumPy, YOLOv8, React Native, Expo, pytest, Jest, property-based testing
